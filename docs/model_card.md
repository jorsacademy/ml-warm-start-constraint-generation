# Model Card

## Model

`ConstraintScorer` is a feed-forward neural network that maps one 21-dimensional candidate-constraint feature vector to one scalar logit. Hidden layers use SiLU activations. The model is trained separately for each label target.

## Intended use

The model is intended for research on warm-starting the exact TSP subtour-constraint-generation loop supplied in this repository. It ranks already valid canonical SEC candidates for small Euclidean TSP instances.

## Out-of-scope use

The model should not be used as:

- an optimality or feasibility certificate;
- a general TSP solver;
- a validator of arbitrary inequalities;
- a replacement for exact separation;
- a production solver component without independent profiling and validation;
- a model for non-Euclidean, asymmetric, time-windowed, capacitated, or otherwise modified routing formulations without retraining and redesign.

## Inputs

The model receives complement-invariant geometric statistics of one canonical cut and global instance descriptors. It does not receive:

- the exact tour;
- the current MILP incumbent;
- dual values;
- cold-trajectory information;
- target labels at inference time.

## Outputs

The output is an uncalibrated ranking logit. Its numerical value is not a probability guarantee. Top-\(k\) ranking is used to select the preload.

## Training targets

Principal targets:

- `invariant`: deletion-minimal one-shot sufficient core;
- `binding`: all canonical SECs tight at the selected exact tour.

Additional diagnostic targets:

- `trajectory`;
- `initial`.

## Training data

Training data are synthetic Euclidean TSP instances with exact labels generated by the repository. Whole instances are separated across train and validation sets. The candidate class is highly imbalanced, so all positives and a deterministic mixture of hard and random negatives are used.

## Reliability measures

- model dimensions and feature schema are versioned;
- normalization statistics are stored in the state dictionary;
- checkpoints use Safetensors, not pickle;
- tensor keys and shapes load strictly;
- nonfinite parameters, inputs, and outputs are rejected;
- every selected candidate is reconstructed as a typed valid SEC;
- exact online separation continues after inference.

## Known limitations

The MLP scores constraints independently and cannot explicitly reason about redundancy among a selected batch. Complete candidate enumeration is exponential. Training distributions are synthetic. Scores are not calibrated. Different exact-tour tie-breaking or one-shot-core deletion orders may alter labels.

## Fairness and societal impact

The benchmark does not model people or protected attributes. Its primary risks are technical: overstated solver acceleration, use outside the supported formulation, and interpreting heuristic scores as mathematical guarantees.
